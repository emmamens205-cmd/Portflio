# Data Growth Studio

AI Portfolio Prompt

Act as an award-winning UX Designer, Senior Front-end Developer, Creative Director, and Personal Branding Expert.

Design and generate a fully responsive HTML, CSS and JavaScript portfolio website for a modern Digital Marketing & Data Analytics professional.

The website should look like it belongs to someone working in a top marketing agency, consulting firm, or AI startup.

The design should feel premium, elegant and highly interactive—not like a generic portfolio template.

Build everything from scratch using semantic HTML5, modern CSS (Flexbox & Grid), and vanilla JavaScript.

Do not use Bootstrap.

Make the code clean, modular and production-ready.

Use smooth animations, subtle hover effects, scroll animations, counters and modern transitions.

The portfolio must be SEO-friendly and optimized for performance.

Follow Google's Core Web Vitals best practices.

The website should be accessible (WCAG-friendly), mobile-first and responsive across all devices.
